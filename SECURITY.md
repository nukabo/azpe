# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in AZPE, please do not report it publicly via GitHub issues.

Instead, please send an email describing the vulnerability to the project maintainers. Include details on how to reproduce the issue.

Maintainers will review the report and respond within 48 hours.
